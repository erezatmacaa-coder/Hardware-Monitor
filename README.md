# Hardware Monitor 🚀
Python ile geliştirilmiş, anlık CPU ve RAM kullanımını terminal üzerinden takip etmenizi sağlayan basit bir sistem aracı.

## Özellikler
- Anlık CPU takibi.
- RAM kullanım verisi.
- Hafif ve hızlı çalışma.

## Nasıl Çalıştırılır?
1. `pip install psutil` komutunu çalıştırın.
2. `python hardware_monitor.py` ile başlatın.
